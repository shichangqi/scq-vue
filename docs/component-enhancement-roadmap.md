评估依据包括组件源码、类型及方法调用实现，以及演示站的 [组件目录](../playground/src/docs/catalog.ts)、[API 说明](../playground/src/docs/reference.ts)和[扩展组件 API 说明](../playground/src/docs/reference-extended.ts)。每个组件标题均链接到对应实现，便于后续开发核对。

### 1.1 优先级约定

| 优先级 | 含义 | 适用方向 |
| --- | --- | --- |
| P1 | 优先进入候选迭代 | 高频业务能力、跨组件一致性、复杂交互的基础支撑 |
| P2 | 在基础能力稳定后扩展 | 进阶交互、更多展示形态、效率和体验提升 |
| P3 | 有明确业务需求再做 | 专业场景、较重能力、可先用组合示例验证的功能 |

每节的“已有”只是能力摘要，并非完整 API；“建议”包含真正新增的功能，也包含把现有插槽组合升级为更便利、统一的能力。**不能因为列入建议，就认为现有组件完全无法完成该场景。**

文中出现的新属性、事件或方法名均为拟议名称，最终应结合类型设计与兼容性评审确定。尤其不要直接改变已有默认值、事件载荷或受控行为。

## 2. 总体判断与共用能力

当前组件数量已经较完整，下一步不宜单纯追求“再增加几个属性”。更有价值的方向是：

1. **让现有能力接入更一致。** 主题、禁用、尺寸、表单关联、浮层焦点和异步状态不应在不同组件中呈现不同规则。
2. **补齐高频复杂场景。** 优先考虑表格筛选与列管理、表单联动、远程选择器和大文件上传管理。
3. **复用已经具备的基础。** 远程搜索、异步校验、树懒加载、动态高度虚拟列表、图片预览、上传取消与重试等已经存在，应在此基础上深化，而不是重新列为从零开发。
4. **简单组件保持简单。** 间距、分割线、空状态等优先补充稳定的样式约定和组合示例，不必为每种视觉变化增加一个属性。

建议先形成以下共用能力，后面的逐组件建议以 T1～T7 引用它们。

| 编号 | 共用能力 | 当前基础与后续建议 |
| --- | --- | --- |
| T1 | 配置、主题与国际化 | [配置上下文](../src/components/ConfigProvider/context.ts)已有嵌套配置、中英文、主题和 token。补齐尚未接入组件的尺寸、禁用和文案继承；明确显式属性与上下文的优先级；让 Teleport 与方法调用的配置来源可控；再扩展自定义语言包、RTL 和组件级 token。 |
| T2 | 表单字段协议 | [表单上下文](../src/components/Form/context.ts)已有字段注册、嵌套路径、校验与重置。继续统一字段 ID、标签、错误描述、禁用、校验触发、dirty/touched/pending 状态及聚焦接口，覆盖原生输入与复杂选择器。 |
| T3 | 浮层生命周期 | [模态工具](../src/utils/modal.ts)已有焦点管理、滚动锁计数和 Escape 栈；[浮层面板](../src/utils/FloatingPanel.vue)已有自动定位与避让。优先让旧浮层接入这些能力，再扩展关闭拦截、初始焦点、嵌套浮层协作、箭头及定位边界。 |
| T4 | 异步交互协议 | [自动补全](../src/components/AutoComplete/AutoComplete.vue)、[树](../src/components/Tree/Tree.vue)、[上传](../src/components/Upload/Upload.vue)、[气泡确认框](../src/components/Popconfirm/Popconfirm.vue)已有取消、过期结果隔离或错误事件等实践。复用其模式，统一待处理、拒绝、失败、取消和重试的语义；有实际重复时再提取公共工具。 |
| T5 | 大数据与滚动 | [虚拟列表](../src/components/VirtualList/VirtualList.vue)已有固定及动态高度模式。优先接入选择器、树、穿梭框和表格，不另外实现多套虚拟滚动；同时设计按 key 定位、滚动锚点保持和焦点保持。 |
| T6 | 导航适配 | 链接、菜单、面包屑、标签栏可共享可选路由适配方式，支持路由选中态和导航守卫，但不把 Vue Router 变成所有组件使用者的必需运行时依赖。 |
| T7 | 公共 API 与验证 | 每项能力同步检查[公共导出](../src/index.ts)、[包导出与构建脚本](../package.json)、[样式目录](../styles)、[演示文档](../playground/src/docs)和[测试目录](../tests)。让按组件导入、完整导入、类型提示和中英文示例保持一致。 |

## 3. 逐组件功能建议

### 3.1 基础与布局：10 个

#### [ConfigProvider](../src/components/ConfigProvider/ConfigProvider.vue) 全局配置

- **已有：** 尺寸、禁用、中英文、亮暗主题、token 覆盖与嵌套继承。
- **P1：** 完成 T1 接入矩阵，特别是旧控件及方法创建的浮层；提供绑定当前配置作用域的调用方式，避免业务反复手传上下文。
- **P2：** 自定义语言包、跟随系统的主题模式、RTL、组件级默认配置；明确嵌套配置合并和运行时更新规则。
- **验收重点：** 显式属性不被全局配置覆盖；嵌套配置相互隔离；主题和语言切换后，页面内与传送到外部容器的内容同步更新。

#### [Button](../src/components/Button/Button.vue) 按钮

- **已有：** 多种语义类型、尺寸、朴素/圆角/圆形/文字/链接外观、加载态和原生按钮类型。
- **P1：** 接入统一尺寸、禁用及表单上下文；保留未使用上下文时的现有默认行为。
- **P2：** 前后图标与自定义 loading 区域的便捷接口；可选加载延迟、最短展示时间和块级布局。已有默认插槽仍可自由组合，不强制改写。
- **验收重点：** 加载时禁止重复操作；短请求不闪烁；加载切换不明显改变按钮宽度；原生提交与重置语义保持不变。

#### [Icon](../src/components/Icon/Icon.vue) 图标

- **已有：** 图标名称、尺寸、颜色、线框/实心变体；当前工作区已接入品牌图标，不能再把“增加品牌图标”作为完全缺失的能力。
- **P1：** 区分装饰图标与语义图标，支持可访问名称、标题及相应 SVG 语义；默认仍按装饰图标使用。
- **P2：** 旋转、翻转、旋转动画等便捷能力；自定义图标注册与名称校验，未知名称的开发提示应与现有回退行为兼容。
- **P3：** 图标级独立导出或更细粒度资源包；先测量真实打包收益，不与已有“按组件导入”混为一谈。
- **验收重点：** 装饰图标不被重复朗读；动画遵循减少动态效果设置；新增资源不影响现有名称和变体回退。

#### [Space](../src/components/Space/Space.vue) 间距

- **已有：** 横纵排列、单值/双值间距、对齐、换行和填充。
- **P2：** 支持命名间距 token 和响应式间距，减少业务自行维护不同屏宽下的间距规则。
- **P3：** 分隔内容插槽；按钮组、紧凑表单组的组合示例。紧凑边框合并应先用示例验证，不急于扩成新的布局体系。
- **验收重点：** 空节点和条件渲染节点不产生多余分隔符；换行及纵向布局下间距一致。

#### [Divider](../src/components/Divider/Divider.vue) 分割线

- **已有：** 横纵分割、文字位置和虚线。
- **P2：** 整理颜色、粗细、间距的稳定样式 token 与示例，优先于增加大量一次性属性。
- **P3：** 内容区缩进、逻辑方向的 start/end 对齐，以及与 RTL 配合的文字位置约定。
- **验收重点：** 保留 separator 语义；装饰文字不造成重复朗读；纵向分割线在不同字号下对齐正常。

#### [Link](../src/components/Link/Link.vue) 链接

- **已有：** 链接/按钮两种语义、图标、状态色、下划线、禁用和新窗口链接处理。
- **P2：** 接入 T6，支持可选路由渲染适配与当前路由状态；不要求普通链接引入路由库。
- **P2：** 后置图标、外链标识和等待导航时的加载反馈；保留默认插槽及原生属性透传。
- **验收重点：** 禁用状态不能导航；鼠标、键盘和辅助技术看到的交互语义一致；已有外链处理规则不退化。

#### [Typography](../src/components/Typography/Typography.vue) 文字

- **已有：** 多种语义标签、文字样式、单行省略、多行截断、复制及复制失败事件。
- **P1：** 截断内容的展开/收起和实际溢出判断；只在确实截断时展示完整文本提示。
- **P2：** 行内编辑模式，提供编辑、确认、取消和异步保存反馈，支持自定义显示内容与编辑值。
- **验收重点：** 复制默认取得完整内容；编辑失败不丢失输入；容器宽度改变后及时更新截断状态。

#### [Grid](../src/components/Grid/Grid.vue) 栅格

- **已有：** 数值或响应式列数、间距、对齐及语义容器标签。
- **P2：** 子项跨列、跨行、偏移和排序的统一约定，优先提供 CSS 变量与插槽组合示例。
- **P2：** 基于最小项宽的自动填充布局，以及可选自定义断点，适配卡片墙和不固定列数的内容。
- **验收重点：** 小屏不产生意外横向滚动；跨列范围与当前列数一致；视觉排序不破坏合理的键盘阅读顺序。

#### [Layout](../src/components/Layout/Layout.vue) 布局

- **已有：** 横纵 Flex 布局、对齐、间距、换行、反向排列及语义标签。
- **P2：** 响应式方向、间距和对齐规则，覆盖桌面横排、移动端纵排。
- **P3：** 固定区与弹性区、可滚动内容区、吸顶工具栏等组合范式；优先文档化 `min-width`、`min-height` 和溢出规则，不直接引入页面管理器。
- **验收重点：** 长内容不撑破弹性区域；切换方向不丢失表单或滚动区状态。

#### [Container](../src/components/Container/Container.vue) 布局容器

- **已有：** 页头、侧栏、主体、页脚插槽，最大宽度、流式布局和左右侧栏。
- **P2：** 受控侧栏折叠；窄屏时可选择抽屉式侧栏，复用现有浮层而非另建遮罩逻辑。
- **P2：** 固定页头/页脚和独立主区滚动的标准组合；为可调整侧栏宽度提供边界和键盘操作方案。
- **验收重点：** 收起侧栏后焦点有合理去向；抽屉关闭不影响主体；持久化布局偏好由业务显式接入。

### 3.2 表单与选择：19 个

#### [Input](../src/components/Input/Input.vue) 输入框

- **已有：** 多种输入类型、清空、密码显隐、字数统计、自动高度文本域及前后插槽。
- **P1：** 统一中文输入法组合输入期间的值提交规则；接入 T2，将标签、错误描述和原生输入属性可靠关联到真实输入元素。
- **P2：** 文本域 `minRows/maxRows`、行数与高度边界；可选字素计数方式，避免 emoji 等内容的计数体验不一致。
- **P2：** 格式化/解析接口及输入掩码组合示例，明确显示字符串与提交值的区别。
- **验收重点：** 组合输入完成时不重复提交；只读与禁用时不清空或切换密码；文本域达到最大高度后正常滚动。

#### [Form](../src/components/Form/Form.vue) 表单

- **已有：** 异步规则校验、整表/指定字段校验、重置、清除校验、嵌套字段路径及布局配置。
- **P1：** dirty/touched/pending 状态、错误摘要、滚动到字段和聚焦首个错误；让业务不用自行遍历组件实例。
- **P1：** 字段依赖与交叉校验，支持依赖变化触发校验以及可选防抖；复用已有过期结果隔离实践。
- **P2：** 动态字段和数组项的生命周期约定；明确隐藏字段是否参与校验、删除字段如何清理错误、何时更新重置基准。
- **验收重点：** 较早的异步结果不能覆盖最新结果；动态字段删除后不残留错误；重置结果与声明的初始值策略一致。

#### [FormItem](../src/components/Form/FormItem.vue) 表单项

- **已有：** 字段级规则、必填标记、手动错误、标签和错误插槽、校验中状态及单项重置。
- **P1：** 自动关联控件 ID、标签、错误描述和 `aria-invalid`；复合控件、多输入项需要显式的关联出口。
- **P2：** 将现有校验状态暴露给反馈图标或作用域插槽；补充帮助文案、标签提示、单项标签宽度与错误展示方式。
- **验收重点：** 错误只关联当前字段；辅助技术可定位错误内容；手动错误与规则错误的优先级清晰。

#### [InputNumber](../src/components/InputNumber/InputNumber.vue) 数字输入框

- **已有：** 范围、步长、精度、加减按钮、方向键、只读和空值。
- **P1：** 严格按步长取值的可选模式；千分位、金额和单位显示的 formatter/parser 机制。
- **P2：** 大整数或高精度小数的字符串模式；按住加减按钮连续变化，并在失焦、取消指针操作后立即停止。
- **验收重点：** 小数运算、空值和范围边界正确；字符串模式不能内部转成浮点数后再声称无精度损失。

#### [Switch](../src/components/Switch/Switch.vue) 开关

- **已有：** 布尔值绑定、尺寸、文字、禁用和加载态。
- **P1：** 自定义开启/关闭值，支持业务常见的字符串或数字状态，保留布尔值默认行为。
- **P1：** 异步切换前拦截、自动 pending 和失败反馈；失败时保持原值，取消时避免过期结果回写。
- **验收重点：** 快速点击只产生有效的一次切换；拒绝或失败不发出成功形态的 change；既有受控模式不退化。

#### [Radio](../src/components/Radio/Radio.vue) 单选框

- **已有：** 独立或分组使用、值绑定、禁用、尺寸和标签插槽。
- **P1：** 补齐 T1/T2 的配置、字段 ID、焦点和错误关联能力。
- **P2：** 按钮式、卡片式等选择外观，以及只读交互；使用同一选择语义，避免视觉样式产生另一套状态逻辑。
- **验收重点：** 外观变化不影响原生单选语义；点击标签与键盘选择行为一致。

#### [RadioGroup](../src/components/Radio/RadioGroup.vue) 单选框组

- **已有：** 分组值、名称、方向及组级尺寸/禁用下发。
- **P1：** 自动生成独立组名、完善焦点定位；提供数据驱动 options 与选项插槽，保留声明式子组件用法。
- **P2：** 组级切换拦截、只读及均分/紧凑布局。
- **验收重点：** 页面内多个未手写 name 的组互不干扰；禁用项被正确跳过；异步拒绝时不产生选中态闪变。

#### [Checkbox](../src/components/Checkbox/Checkbox.vue) 多选框

- **已有：** 独立布尔值、分组值、半选态、禁用、尺寸和标签插槽。
- **P1：** 可选的自定义选中/未选中值，并统一字段关联与焦点接口。
- **P2：** 只读、按钮式或卡片式外观；明确半选态是外部展示状态，不隐式改写业务选中值。
- **验收重点：** 选中、未选中、半选三种状态的视觉和可访问语义一致；受控更新后状态同步。

#### [CheckboxGroup](../src/components/Checkbox/CheckboxGroup.vue) 多选框组

- **已有：** 数组值绑定、横纵方向及组级尺寸/禁用。
- **P1：** 最少/最多选择数量及越界反馈；达到上限时仍允许取消已选项。
- **P2：** options 数据模式、全选/反选便捷能力；明确搜索过滤后操作“可见项”还是“全部项”。
- **验收重点：** 全选正确排除不可选项；过滤和上限组合时结果可预测；不丢失被业务保留的禁用项状态。

## 5. 后续实现的验收与回归要求

以下是**建议目标与测试方法，不是本次测得的数据或已达成的性能承诺**。涉及耗时的目标，应记录测试设备、浏览器、构建模式和数据规模，再形成项目基准。

### 5.1 通用行为

- **兼容性：** 默认属性、现有事件载荷、插槽、组件别名和导入路径不改变；新增模式通过显式配置启用。
- **受控行为：** 外部值始终是受控模式的最终来源；内部等待态不能在请求完成后覆盖较新的外部值。
- **异步行为：** 覆盖成功、返回 false、抛错、取消、重复点击、卸载和响应乱序；实际失败必须通过已有或新增的标准错误事件/可见状态暴露。
- **输入与表单：** 组合输入、清空、失焦和提交分别测试；多个表单、动态字段和传送到外部容器的控件不能互相污染。
- **可访问性：** 检查名称、角色、状态、方向键/Tab/Escape、禁用与只读、焦点归还，以及减少动态效果设置。
- **跨端：** 至少验证 320/375/768/1440 CSS 像素宽度、亮暗主题、中英文、长文本和 200% 缩放；含手势功能需要实际触摸设备或相应浏览器环境验证。
- **资源释放：** 关闭/卸载后清除属于该组件的监听器、观察器、计时器和请求；不得释放其他组件仍在使用的全局资源。

## 6. 需要明确保留的边界

1. **组件库不承担业务后端。** 远程检索、上传、路由鉴权、通知存储等提供接口与事件，具体网络请求和权限判断由业务实现。
2. **重功能先确认协议。** 断点续传依赖服务端；日期时间与特殊历法需要明确时区/地区约定。
3. **已有插槽能稳定满足的场景，先做组合示例。** 不强行为简单组件增加复杂配置，更不为凑功能数量新增公共组件。
4. **不默认采集或持久化用户数据。** 搜索历史、通知记录、布局偏好等均由业务显式决定存储方式。
5. **先完成一个可验证闭环，再扩展组合。** 尤其是表格、树和虚拟滚动，必须说明支持的组合与限制，避免“属性都有，但放在一起不能用”。

**结论：** 当前最值得优先投入的不是继续扩充组件数量，而是统一配置/表单/浮层协议，并深化表格、远程选择与上传管理。其余组件按业务频率逐步完善展示形态和组合体验，可让组件库从“覆盖较全”进一步走向“接入一致、复杂场景可靠”。

### 7.1 覆盖优先级与边界

- 普通控件：**显式属性 > 最近配置作用域 > 库默认值**。布尔属性未传与 `false` 分开处理，显式 `disabled=false` 可覆盖 Provider。
- `RadioGroup` / `CheckboxGroup` 保留已有的组尺寸优先与整组禁用约束；需要解除 Provider 导致的整组禁用时，应在组上显式传入 `disabled=false`。`Collapse` 的整组禁用约束同样保留。
- `Form` 可继承或显式设置 `size`、`disabled`，并向子控件提供该配置，复杂选择器也能接收禁用更新。原生 `fieldset` 的禁用约束仍然有效；字段 ID、dirty/touched/pending 等属于 W3。
- 嵌套 Provider 的标量就近覆盖，`tokens` 按键合并；更新与删除 token 均响应式生效。显式浅色主题会重置外层暗色的配色、阴影和 `color-scheme`。
- 显式语义色 token 的渐变、hover/active、浅色背景及焦点色通过标准 CSS `color-mix()` 派生，规则集中管理；未设置 token 时保留原有调色板。Button 的独立样式与组件样式使用同一组变量，避免固定渐变遮住配置色。
- 只有标准 `small/default/large` 尺寸参与继承；字号、图标大小、间距、浮层宽度等数字或 CSS 长度不重新解释。没有整体 `disabled` 属性的展示/导航组件，不把数据项的 `disabled` 强行变成全局禁用入口。
- 仅默认 UI 文案跟随语言，显式传入的文本、插槽、选项、校验规则消息等仍由业务控制。无 Provider 时，原有尺寸、禁用、受控值、事件载荷和导入路径不变；新接入控件的默认无障碍文案统一跟随库默认中文语言。
- 禁用约束针对用户交互；业务主动更新受控值，以及 Input / Select 既有的命令式 `clear()` 重置能力保持不变。

### 7.3 方法调用作用域

新增 `useDialog()`、`useModal()`、`useMessage()`、`useToast()`、`useNotification()`，分别从完整入口和对应的 `scq-vue/components/...` 入口导出。它们复用现有方法实现，不创建另一套反馈组件。

1. 必须在 Provider **后代组件的 setup** 中调用；在创建 Provider 的父组件 setup 中调用，只能取得父级配置。组件外调用会明确抛错。
2. 捕获当前配置的响应式引用及应用上下文，已经打开的默认标题、按钮文案和主题会随 Provider 更新。显式标题、按钮文字及内容保持原值；实例的 `update` / `close` 接口仍可使用。
3. 每次 hook 调用拥有自己的方法实例作用域。`destroyAll` / `clear` / `closeAll` 只清理该作用域，所属组件卸载时自动释放实例、计时器和观察器；强制卸载清理不等待业务关闭拦截。`setGlobalZIndex` 的名称与全局语义不变。
4. Toast 在**同作用域、同目标容器**内替换；Notification 在**同作用域、同目标容器、同 id**下更新。不同作用域可同时存在，通知仍共用目标内的位置堆叠；多个 Toast 同位置时需业务自行选择位置或容器。
5. 既有静态方法保留，仍可在组件外调用；没有显式 `appContext` 时使用库默认配置，不隐式读取最近一次使用的 Provider。五类静态创建方法均支持可选的第二个 `appContext` 参数。作用域方法的绑定不能改换，传入不同上下文会明确抛错，避免实例逃逸出所属组件的清理范围；需要指定其他上下文时应使用静态方法。全局静态批量清理仍作用于所有方法实例。
6. Teleport 的配置来自创建组件的逻辑父级，不是目标 DOM 容器。通过 Provider 声明的主题/token 可以同步到 `body` 或自定义目标；不承诺复制目标外任意祖先元素上手写的 CSS。

### 9.2 AutoComplete 已实施范围

- **W3 字段协议：** 复用 `useFormControl`，将 ID、标签、帮助、错误、required/pending 语义关联到真实输入框；接入聚焦、dirty/touched/reset 和整表禁用。传送到外部容器的分页按钮仍属于当前字段，离开后才触发字段失焦。
- **W4 异步与输入：** 复用 `useLatestRequest` 和 `useCompositionModel`。保留 `(query, signal)` 的原有提供器，扩展第三参数 `{ page, pageSize }`；输入法提交不重复触发查询。新查询、外部值、关闭、禁用/只读、提供器替换和卸载都会隔离旧请求；取消不是业务错误。
- **本地建议：** 显式 `groupBy` 分组、`highlightMatch` 字面匹配高亮、`filterMethod` 自定义过滤和 `minLength` 最小输入长度。分组标题不参与选中；高亮不解析 HTML；label 与 value 不同仍提交 value。保留原有 default/empty 插槽，新增 group 插槽。
- **分页与缓存：** 显式 `pagination`，默认 `pageSize=10`；支持本地切片和远程 `{ list, total? }`，跨页远程数据需提供 total。同查询/页码/页大小的防抖及在途请求去重；`cacheTtl=0` 默认不缓存完成结果，正值为缓存有效毫秒数。缓存按实例隔离，不写本地存储；提供器、页大小、分页模式和 TTL 变化使缓存失效。
- **错误与刷新：** 无效远程结果和当前请求失败显示错误/重试，触发 error；未监听时沿用共用工具记录错误。`refresh()` / `retry()` 打开面板并立即查询当前页，失效该页缓存并跳过防抖，返回结果是否成功应用；失败不会在下次打开时复活该页旧缓存。`clearCache()` 清空缓存并取消在途请求，不改写输入。
- **W8 虚拟选项：** 显式 `virtual`，复用 VirtualList 的稳定 key、固定行高及活动项保留；分组标题同样虚拟渲染。默认 `height/itemHeight/overscan=260/44/5`；普通模式下 height 控制最大列表高度。方向键、Home/End、翻页和重试后活动项保持可用，键盘目标滚动到视口内；翻页不提交输入值。
- **接口与演示：** 完整与按需入口同步导出选项、查询上下文、结果、提供器、props、slots 和实例类型；按需样式补齐 VirtualList 依赖。新增[可复制增强示例](../playground/src/components/examples/AutoCompleteEnhancementExample.vue)，接入[中英文 API 说明](../playground/src/docs/reference-enhancements.ts)，不移除旧示例。
